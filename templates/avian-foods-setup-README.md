## Step-by-step onboarding

### 1. Create the tenant Sheet
From the master registry's `🏬 StorePro Onboarding` menu → **Create new tenant store** with:
- Store name: **Avian Foods**
- Type: **Meat**
- Slug: `avian`

This copies the template Sheet and creates a registry row.

### 2. Add the registry row (or verify autogenerated)
In the master registry's `Stores` tab, the row should look like:

| Column | Value |
|---|---|
| Slug | `avian` |
| ShopName | Avian Foods |
| Type | Meat |
| Subdomain | `avian` |
| Phone | 917777848850 |
| City | Bhopal |
| SheetID | (auto-filled) |
| ScriptURL | (paste tenant's `/exec` URL after deploy) |

### 3. Populate Config + Products
- Open the tenant Sheet
- Open `avian-foods-config.csv` in Excel/Sheets, copy all rows, paste into the tenant's **Config** tab (overwriting any existing rows for the same key)
- Open `avian-foods-products.csv`, copy all rows, paste into the **Products** tab (replace the template starter rows)
- Save

### 4. Deploy the Apps Script
In the tenant Sheet → Extensions → Apps Script:
- Deploy → New deployment → Web app → Anyone → copy the `/exec` URL
- Paste that URL into the registry row's `ScriptURL` column AND into Script Properties as `SCRIPT_URL`

### 5. Set the Push secret
- Run `printPushSecretForSlug("avian")` in the master registry editor
- Copy the resulting hex secret
- In the tenant's Apps Script → Project Settings → Script Properties: set `PUSH_SECRET` = (the hex)

### 6. (Optional) Telegram alerts
- Create a bot with @BotFather, get the token + chat ID
- In tenant Apps Script Sheet menu → 🔒 Admin → Set Telegram bot token + Set Telegram chat IDs
- Run `setTelegramWebhook` from the editor

### 7. Verify
- Visit `https://avian.storepro.in/` — should land on the **lovable home.html** with deep-blue theme, hero stats, reviews, gallery, social links
- Tap **Order Now** — routes to `meatshop.html?store=avian` with the 18 chicken cuts
- Place a test order, confirm it lands in the Sheet + alert hits Telegram

### 8. (Optional) Wire up real Google Reviews
The Config rows ship with 5 hand-written testimonials, but home.html will happily render Avian's actual Google Maps reviews instead. Setup:

- In tenant Apps Script editor: **🔒 Admin → 🌟 Set Google Places API key…** (paste the master Places API key)
- **🔒 Admin → 🌟 Find my Google Place ID…** (search "Avian Foods Bhopal" → copy ID from logs)
- **🔒 Admin → 🌟 Set Google Place ID…** (paste the `ChIJ…` string)
- **🔒 Admin → 🌟 Refresh Google reviews now** (verify it works — the Review1-5 rows in Config get overwritten with real Google data)
- **🔒 Admin → 🌟 Install daily Google reviews refresh** (auto-pull at 4am)

After this runs, every storefront page reads the latest 5 Google reviews + the live star rating + total review count. No frontend changes required — home.html already reads `Rating`, `RatingCount`, `Review1Name`, `Review1Stars`, `Review1Text`, `Review1Date`, `Review1Photo` and the new `RateUsURL`.

**Cost reminder:** Places API (New) details ≈ $17/1000 calls. Daily refresh × 30 tenants × 30 days ≈ 900 calls/mo ≈ $15 — covered by Google's $200 free credit. Switch to weekly refresh if you cross 50+ tenants.

## Notes & decisions

- **Template choice:** `meatshop.html` is the natural fit — kg/g unit handling, negotiate-price feature, freshness cues. Routing is automatic via `Type=Meat`.
- **Homepage on:** Avian's website has rich brand content (about, reviews, gallery), so we load the lovable `home.html` first. Customer taps "Order" to get to the menu UI.
- **Brand color blue:** `home.html` reads `BrandColor` and applies `#1e40af` consistently across hero, CTAs, accents. The order screen (`meatshop.html`) currently has a hardcoded red theme — known limitation, see open task to wire `BrandColor` into meatshop.html if you want the order page blue too.
- **Pricing:** Avian Foods doesn't publish prices online. Values in the Products CSV are realistic premium-tier Bhopal market rates for May 2026 — adjust before going live.
- **Hero image:** placeholder Unsplash chicken photo. Upload Avian's own product imagery via the dashboard's Theme & Photos for best results.
- **GPS gate:** `RequireGPS=yes` and `DeliveryRadiusKm=12` enabled (Bhopal city radius). Avian's claim of 90-120 min delivery suggests they don't go far. Customers outside this radius will see "out of delivery range" before checkout.
- **Sunday hours** shorter (8-15:00) — typical for Indian meat shops; adjust if needed.
